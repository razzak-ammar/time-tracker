# Recently Deleted UI work notes

- **Visual thesis:** A quiet operational recovery surface: warm amber status, thin dividers, and intentionally sparse controls that make restoring data feel safe and predictable.
- **Content plan:** Orientation (30-day policy and item count), recoverable projects, recoverable time entries, then a small empty state when nothing is retained.
- **Interaction thesis:** Rows gain a subtle surface tint on hover; Restore has the single accent treatment; irreversible removal uses a confirmation dialog and a short, explicit consequence.
